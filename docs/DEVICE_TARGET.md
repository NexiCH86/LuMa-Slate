# Device target – BOOX Tab Ultra C Pro

LuMa Slate is designed around the physical device rather than a generic tablet breakpoint.

## Display target

- Native B/W pixel grid: 1860 × 2480 in portrait
- B/W density: 300 ppi
- Color pixel grid: 930 × 1240 in portrait
- Color density: 150 ppi
- Display technology: Kaleido 3 / Carta 1200

## UI implications

- Typography carries structure; color does not.
- Petrol/cyan accents remain secondary and non-essential.
- Cards use hard edges and subtle borders instead of blurred shadows.
- No continuous animation.
- Navigation and core actions use large touch areas.
- Portrait orientation is locked in the web app manifest and landscape receives a deliberate orientation notice.
